# Численная проверка энергетической асимптотики

Численная проверка однобитовой энергетической асимптотики. Единицы энергии: Eκ = 1; F = ΔE/Eκ. Вычисления в double precision, NumPy 2.3.5.

## Методика

1. Квадратура. Для каждого t решено уравнение нормировки интеграла из приложения A бисекцией по c. Интегрирование Гаусса–Лежандра: 64, 128, 256 узлов. Энергия вычислена устойчивой формулой F = [(v−1)²/v]/4, где v = √(c−2t cos z); улучшение ошибки δ = [cos z (1/v−1)]/2. Эти равенства используют [1/v] = 1. Формулы вычисления не используют проверяемый коэффициент B.

2. Независимая минимизация F−tδ в реальном классе α = φ/2 + Σ aₙ sin(2nφ). Энергия вычисляется по коэффициентам Фурье, ошибка — интегрированием исходного эффекта, без квадратуры приложения. Использован метод Ньютона с аналитическими градиентом, гессианом и поиском шага. Остановка при норме градиента < 10⁻¹³ либо норме ньютоновского шага < 3×10⁻¹⁶; конечная невязка обязательно проверяется на порог 10⁻¹¹. Поиск шага учитывает округление функционала. Неудача приводит к исключению. Число гармоник: 8, 16, 32, 64. Интегралы разбиты в точках разрыва sign(cos φ); по 256 узлов на четверть, контроль с 384. Начальные коэффициенты нулевые, дополнительно три случайных старта. Коэффициент B и функция h в оптимизатор не передаются.

Это оптимизация лагранжиана, а не отдельная задача с фиксированным δ: для каждого решения измерены его собственные F и δ. Симметрия профиля ограничена указанным реальным подпространством. Поиск по всем комплексным инструментам и скрытым каналам не проводился.

3. Спектральный контроль. По численно оптимизированному профилю построены qₜ и комплексные матрицы Галёркина операторов L₀,ₜ и L₁,ₜ на антипериодическом базисе exp(i(l+1/2)φ). Для cutoff = M использовано 2M мод. Проверены низшие уровни обоих операторов при t = 0.02 и M = 8, 16, 32, 64. Профиль и оператор уточнялись одновременно; отдельное увеличение порядка квадратуры выполнено на последнем разрешении.

## Вывод и ограничения

На проверенных разрешениях численная проверка поддерживает коэффициент 2π²/(π²−8), нормировки и локальную спектральную картину. Расхождения, указывающие на ошибку множителя или знака, не обнаружены. Проверка не устанавливает новизну, не строит полную границу, не даёт строгого δ₀ или сертифицированного остатка и не заменяет глобальную нижнюю оценку для комплексных счётных каналов.

## Воспроизведение

Требуются Python 3 и NumPy; SciPy не используется.

```sh
OPENBLAS_NUM_THREADS=1 python3 check.py
python3 validate.py
python3 summarize.py
python3 export_tex.py
```

check.py сохраняет все результаты в results.json; validate.py проверяет производные конечными разностями и повторяемость; summarize.py восстанавливает этот отчёт; export_tex.py генерирует векторный рисунок PGFPlots и таблицу в ../figures/. Команды выше выполняются из каталога numerical-check/. Дополнительные двухбитовые проверки запускаются командами `python3 check_two_digits.py` и `python3 verify_two_digits.py`; они сохраняют two-digits-results.json и two-digits-verification.json.

## Independent joint optimisation (review revision)

`check_joint_optimization.py` optimises the three periodic tangent fields of a real, pointwise-normalised four-channel instrument. The Fourier coefficients of all fields are varied jointly using L-BFGS. The optimiser does not use the analytic attaining profile, B, chi, or a separated energy formula. This is a local finite-dimensional numerical check, not a proof of global optimality.

The six multiplier scales are 0.04, 0.02, 0.01, 0.005, 0.0025 and 0.00125; the five directions are (1,0), (0,1), (1,1/2), (1,1) and (1,2). Fourier cutoffs are 16, 32, 64 and 128, with 192 Gauss–Legendre nodes on each quarter. The three interior directions determine the free coefficients in F = A*d1^2 + 2*K*d1*d2 + C*d2^2. Raw observables, finite-scale fits, quadratic extrapolations over the four smallest scales, and control runs are in `joint-optimization-results.json`.

At cutoff 128 the extrapolated coefficients are (10.5579674, -1.7e-7, 3.6597942), consistent with the analytical limits (10.5579602, 0, 3.6597924) as resolution increases. These values are empirical extrapolations, not certified error bars. At finite scale the fitted mixed coefficient is not assumed to vanish. The separate mixed dual difference also tends towards zero.

`validate_joint_optimization.py` tests eight gradient directions at three finite-difference steps and computes the energy independently by FFT. The maximum gradient discrepancy is 1.6e-12, the random-start dual spread is 4.9e-14, and increasing quadrature order from 192 to 256 at cutoff 128 changes the dual objective by about 1e-18. Results are in `joint-optimization-validation.json`.

Run with the same Python/NumPy requirements as above:

```sh
OPENBLAS_NUM_THREADS=1 python3 check_joint_optimization.py
python3 validate_joint_optimization.py
```
